Spot Finder

This project's name is Spot-Finder.

We made this project for the course "Introduction to Internet and Web", with the purpose of finding dating spots or tourist attraction places that could make it easier to search and find and then plan the routes for whoever in Busan area.

Due to not enough time to work on this project, this project may feel incomplete. But for now it does what it should do, the basic actions are already included. But if possible we will be developing this project further to make it a real life helper.
